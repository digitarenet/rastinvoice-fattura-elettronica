**Windows: avviso di sicurezza al primo avvio.** Il file `.exe` non ha ancora una firma digitale, quindi
Windows mostra la finestra «Windows ha protetto il PC». Per avviare RastInvoice scegliere **Ulteriori
informazioni** e poi **Esegui comunque**. Anche il browser può segnalare che il file «non viene scaricato
comunemente»: scegliere **Mantieni**. La versione del Microsoft Store, in arrivo, è firmata e non mostra
avvisi. Il programma non richiede installazione: al primo avvio chiede se salvare i dati nel profilo utente o
accanto al file (modalità portable, per esempio su una chiavetta USB). Richiede WebView2, già presente in
Windows 11 e in Windows 10 aggiornato.

**Linux:** le versioni `.deb`, `.rpm` e AppImage si aggiornano dall'applicazione (Impostazioni).
