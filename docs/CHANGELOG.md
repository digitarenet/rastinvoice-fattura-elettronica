# Registro delle modifiche

Novità, miglioramenti e correzioni di RastInvoice (fino alla 0.9.0 chiamato RustinVoice).

## 1.3.0 - 2026-11-14

### Aggiunto
- Versione per Windows scaricabile come file `.exe`, senza installazione.

### Modificato
- Il pulsante Scarica delle Impostazioni apre la pagina di download del sito.

## 1.2.2

### Corretto
- Elenco vuoto scegliendo un anno dopo Contrassegnate, Da leggere o Con anomalie.
- Alcune fatture vuote con il foglio di stile AssoSoftware.

## 1.2.1

### Modificato
- Nuovo logo e nuova icona del programma.

## 1.2.0

### Aggiunto
