# Sicurezza

Per segnalare una vulnerabilità scrivere a **info@digitare.net** indicando la versione
di RustinVoice, il sistema operativo e i passi per riprodurre il problema, se possibile
con un file di esempio privo di dati reali.

Si chiede di non aprire una issue pubblica finché la correzione non è disponibile.
Si riceverà una risposta entro pochi giorni lavorativi.

## Versioni supportate

Le correzioni di sicurezza vengono pubblicate sull'ultima versione disponibile.
